# cargo-maturity

Cargo plugin integration for the `maturity` ecosystem.
Provides the `cargo maturity` command which allows the usage of the common CLI implementations.

## `maturity` ecosystem?

The `maturity` ecosystem is of 5 crates where 2 crates are interfaces and 3 crates are functionalities:

### functionality crates:
- maturity-core
- maturity-macro
- maturity-report

### interface crates:
- cargo-maturity
- maturity-cli
