# maturity-macro

This crate provides attribute macros used to annotate Rust items with maturity information.

## `maturity` ecosystem?

The `maturity` ecosystem is of 5 crates where 2 crates are interfaces and 3 crates are functionalities:

### functionality crates:
- maturity-core
- maturity-macro
- maturity-report

### interface crates:
- cargo-maturity
- maturity-cli
